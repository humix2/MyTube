# MyTube

YouTube を中心に、いくつかの動画サイトを 1 つのウィンドウで切り替えたり、画面分割で並べたりして見られる
Windows アプリ（C# / WPF / WebView2）。
各サイトをそのまま表示するので、ログインすれば登録チャンネル・マイリスト・視聴履歴などはそれぞれのアカウントと同期されます。

## 対応サイト

| サイト | 左メニューの項目 |
|---|---|
| YouTube | 検索・登録チャンネル新着・ホーム・後で見る・再生リスト・履歴・チャンネル管理・急上昇（下の「YouTube の機能」も参照） |
| ニコニコ動画 | トップ・ランキング |
| TVer | ホーム・マイページ・リアルタイム |
| NHK ONE | トップ・番組表（今日）・ラジオ |
| Netflix / Disney+ / Prime Video / Hulu | トップ |
| Twitch | ホーム・フォロー中・ブラウズ |

- 有料配信の DRM（Widevine・PlayReady）にも対応しているので、Netflix などの動画も再生できる
- 上の一覧にないサイトのリンクは既定のブラウザで開く（サイトの一覧は `MyTube/Services/Sites.cs`）

## 共通の機能

- 左端のアイコンの帯でサイトを選ぶと、その右にそのサイト用の項目が出る
  - 選択中の画面に出ているサイトに合わせて、左メニューも自動で切り替わる
  - 左上の ≡ で、アイコンの帯だけの表示に畳める。畳んでいるときは、アイコンにマウスを乗せると項目が横に浮き出る
- 画面分割で最大4つの画面を並べて見られる（タイトルバーの分割ボタン）。画面ごとに別のサイトを開いてもよい
  - 並べ方は 1画面／左右2分割／上下2分割／大1＋小2／4分割／大1＋小3
  - クリックした画面が「選択中」（青枠）になり、左メニュー・検索・戻る/進むはその画面に効く。Ctrl+1〜4 でも選べる
  - 音は決めた 1 画面だけから出し、ほかの画面を操作しても切り替わらない。
    見出しの 🔊 ボタンか、選択中の画面の Ctrl+番号をもう一度押すと、その画面の音に切り替わる。
    音を出している画面の 🔊 を押すとすべて消音。新しく開いた画面は消音で始まる
  - 「大1＋小N」では、小さい画面の見出しのボタンで大きい枠と入れ替えられる
  - 分割中に動画の全画面ボタンを押すと、その枠の中で動画が最大化される。
    全部の枠で同時に最大化できる。見出しのボタンでその動画をモニター全体に広げることもできる（Esc で戻る）
- 小窓（ピクチャインピクチャ）：タイトルバーの小窓ボタンで、選択中の画面をそのまま小さいウィンドウに移して再生する
  - 常に手前に表示し、仮想デスクトップを切り替えても表示されたまま（タスクバーと Alt+Tab には出ない）
  - 小窓の見出しで、音声・動画だけの表示・元の画面に戻す・閉じるを操作できる
- 視聴履歴：左端の帯の一番下のボタンで、どのサイトのものもまとめた視聴履歴を開く
  - アプリで動画を 30 秒以上再生すると記録される（同じ動画は最後に見た日時だけ残す。最大 1000 件）
  - 日付ごとに新しい順に並び、サイトでの絞り込み・タイトルの検索・1 件ずつの削除・すべて消去ができる
  - アプリの外（スマホや普段のブラウザなど）で見たものは入らない
- マウスジェスチャー：右ボタンを押したまま左へドラッグで「戻る」、右へドラッグで「進む」
- 全画面再生時はメニューを隠してウィンドウ全体に表示
- 再生中は、放っておいても画面が暗くなったり消えたりしない
- 拡張機能（uBlock Origin Lite などの広告ブロック）を読み込める（左メニューの「拡張機能」から設定を開ける）
- ウィンドウの位置・サイズを記憶

## YouTube の機能

- 左のメニューから「登録チャンネル新着」「後で見る」「再生リスト」「履歴」などへすぐ移動
  - 動画を開くと左メニューを自動で畳み、一覧に戻ると元に戻る
  - 「急上昇：ゲーム」で、YouTube のゲームの急上昇動画一覧（`/gaming/trending`）を開く
  - 「急上昇：音楽」で、YouTube 音楽チャンネルの再生リスト「人気上昇中の曲 - 日本」（20曲、毎日更新）を開く
    （YouTube 公式の全ジャンルの急上昇ページは 2025年7月に廃止）
- YouTube 側の上部バーと左メニューは隠し、検索はアプリのタイトルバーで行う（左メニューの「検索」か `/` キー）
- 動画一覧で、見た動画を薄く表示して「視聴済み」ラベルを付ける
  - アプリで開いた動画は自動で視聴済みになる
  - サムネイルにマウスを乗せると「視聴済みにする」「未視聴に戻す」を切り替えられる
  - YouTube 側で途中まで見た動画は「視聴履歴あり」と表示
- ライブ配信とそのアーカイブでは、チャットをニコニコ動画のように動画の上に右から左へ流す
  - 操作バーの吹き出しボタンでオン・オフ（状態は記憶）。チャット欄を閉じても流れ続ける
- 動画リンクの右クリック「分割画面で開く」、または中クリック・Ctrl+クリックで、分割した新しい画面に開く
- 「再生が中断されていますか？」の通知（広告ブロックを検知したときに出る）は隠す
- 説明欄などの外部リンクは既定のブラウザで開く

## 実行

```powershell
dotnet run --project MyTube
```

## インストール（exe 化）

```powershell
pwsh tools/install.ps1            # スタートメニューに登録
pwsh tools/install.ps1 -Desktop   # デスクトップにもショートカットを作る
```

`%LOCALAPPDATA%\Programs\MyTube\MyTube.exe` に配置されます。更新するときは MyTube を閉じてから同じコマンドを実行します。
.NET 10 デスクトップランタイムが必要です。

## 配布用 zip の作成

```powershell
pwsh tools/release.ps1
```

`release\` に 2 種類の zip ができます（バージョンは `MyTube.csproj` の `<Version>`）。
中身は `MyTube.exe` と `お読みください.txt` で、広告ブロックの拡張機能は同梱しません。

| ファイル | 内容 |
|---|---|
| `MyTube-<版>-win-x64.zip` | .NET 同梱（約 55MB）。.NET が入っていない PC でも動く |
| `MyTube-<版>-win-x64-requires-dotnet.zip` | .NET 10 デスクトップランタイムが必要（約 0.6MB） |

GitHub に出すときは `v<版>` のタグを付けて push し、Releases の画面で zip をアップロードします。

アイコンは `pwsh tools/make-icon.ps1` で作り直せます（`-Preview <png>` で候補の見比べ、`-Style` でデザイン変更）。

## データの保存場所

`%LOCALAPPDATA%\MyTube`（左下の「データフォルダ」から開けます）

| ファイル / フォルダ | 内容 |
|---|---|
| `settings.json` | ウィンドウ位置、起動ページなど |
| `watched.json` | 視聴済みの動画ID（YouTube の一覧を薄く表示する用） |
| `history.json` | 視聴履歴（すべてのサイト） |
| `WebView2\` | ログイン情報・Cookie |
| `Extensions\` | 広告ブロックなどの拡張機能 |
| `Icons\` | 左端の帯に出す各サイトのアイコン（消すと次の起動で取り直す） |

## 拡張機能（広告ブロックなど）

`Extensions` フォルダに、展開済みの拡張機能をフォルダごと入れてアプリを再起動すると読み込まれます
（`Extensions\<拡張機能名>\manifest.json` という配置）。
