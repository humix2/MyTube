# MyTube

YouTube を見るための Windows アプリ（C# / WPF / WebView2）。
YouTube のサイトをそのまま表示するので、ログインすれば登録チャンネル・おすすめ・履歴はアカウントと同期されます。

## 機能

- 左のメニューから「登録チャンネル新着」「後で見る」「再生リスト」「履歴」などへすぐ移動
  - 左上の ≡ でアイコンだけの表示に畳める。動画を開くと自動で畳み、一覧に戻ると元に戻る
  - 「急上昇：ゲーム」で、YouTube のゲームの急上昇動画一覧（`/gaming/trending`）を開く
  - 「急上昇：音楽」で、YouTube 音楽チャンネルの再生リスト「人気上昇中の曲 - 日本」（20曲、毎日更新）を開く
    （YouTube 公式の全ジャンルの急上昇ページは 2025年7月に廃止）
- YouTube 側の上部バーと左メニューは隠し、検索はアプリのタイトルバーで行う（左メニューの「検索」か `/` キー）
- 広告ブロックとして uBlock Origin Lite を同梱（左メニューの「拡張機能」から設定を開ける）
- 動画一覧で、見た動画を薄く表示して「視聴済み」ラベルを付ける
  - アプリで開いた動画は自動で視聴済みになる
  - サムネイルにマウスを乗せると「視聴済みにする」「未視聴に戻す」を切り替えられる
  - YouTube 側で途中まで見た動画は「視聴履歴あり」と表示
- ライブ配信とそのアーカイブでは、チャットをニコニコ動画のように動画の上に右から左へ流す
  - 操作バーの吹き出しボタンでオン・オフ（状態は記憶）。チャット欄を閉じても流れ続ける
- 画面分割で最大4本の動画を並べて見られる（タイトルバーの分割ボタン）
  - 並べ方は 1画面／左右2分割／上下2分割／大1＋小2／4分割／大1＋小3
  - 動画リンクの右クリック「分割画面で開く」、または中クリック・Ctrl+クリックで新しい画面に開く
  - クリックした画面が「選択中」（青枠）になり、左メニュー・検索・戻る/進むはその画面に効く。Ctrl+1〜4 でも選べる
  - 音は選択中の画面だけ出す（分割ボタンのメニューで切り替え）。各画面の見出しのボタンで個別に消音もできる
  - 「大1＋小N」では、小さい画面の見出しのボタンで大きい枠と入れ替えられる
- 全画面再生時はメニューを隠してウィンドウ全体に表示（分割中はその画面だけ）
- 説明欄などの外部リンクは既定のブラウザで開く
- ウィンドウの位置・サイズを記憶

## 実行

```powershell
dotnet run --project MyTube
```

## インストール（exe 化）

```powershell
pwsh tools/install.ps1            # スタートメニューに登録
pwsh tools/install.ps1 -Desktop   # デスクトップにもショートカットを作る
```

`%LOCALAPPDATA%\Programs\MyTube\MyTube.exe` に配置されます。更新するときは MyTube を閉じてから同じコマンドを実行します。
.NET 10 デスクトップランタイムが必要です。

アイコンは `pwsh tools/make-icon.ps1` で作り直せます（`-Preview <png>` で候補の見比べ、`-Style` でデザイン変更）。

## データの保存場所

`%LOCALAPPDATA%\MyTube`（左下の「データフォルダ」から開けます）

| ファイル / フォルダ | 内容 |
|---|---|
| `settings.json` | ウィンドウ位置、起動ページなど |
| `watched.json` | 視聴済みの動画ID |
| `WebView2\` | ログイン情報・Cookie |
| `Extensions\` | 広告ブロックなどの拡張機能 |

## 拡張機能（広告ブロックなど）

`Extensions` フォルダに、展開済みの拡張機能をフォルダごと入れてアプリを再起動すると読み込まれます
（`Extensions\<拡張機能名>\manifest.json` という配置）。
